Система мониторинга аномалий в транзакциях (Antifraud)

**Цель проекта:** Разработка прототипа аналитической системы для автоматического выявления мошеннических паттернов и снижения финансовых потерь.

**Стек:** PostgreSQL, SQL, Apache Superset (в production).

В папке находятся SQL-скрипты для поиска аномалий:
1. `01_amount_anomaly.sql` — поиск транзакций с аномально высокими суммами.
2. `02_velocity_check.sql` — поиск всплесков активности (Velocity Check).
3. `03_night_activity.sql` — анализ ночной активности.

**Результат**:
Создан работающий прототип логики антифрода. В дальнейшем планируется масштабирование с помощью ETL-процессов (Apache Airflow) и визуализация в дашбордах Superset.
